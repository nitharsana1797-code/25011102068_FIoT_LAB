# CAT 9 – UART Communication using STM32

## Overview
This CAT focuses on implementing UART communication using the STM32F103C8T6 (Blue Pill), exploring data transmission, reception, and LED control through serial communication.

## Tasks

| Task | Description |
|---|---|
| **9A** | Basic UART communication – Character transmission and reception with echo. |
| **9B** | UART-based LED control using serial commands (`LED ON`, `LED OFF`, `LED TOGGLE`). |

## Hardware & Software
- STM32F103C8T6 (Blue Pill)
- USB-to-TTL Converter
- STM32CubeMX
- Keil MDK
- PuTTY / Tera Term

## Communication Configuration
- USART2
- Baud Rate: 115200
- Data Bits: 8
- Parity: None
- Stop Bits: 1

Each task includes its respective source code, circuit diagram, and individual README.
