# CAT 8 – GPIO Input and Output Operations

## Overview
This CAT focuses on STM32 GPIO programming using a push button and LED with the STM32F103C8T6 (Blue Pill) board.

## Tasks

| Task | Description |
|---|---|
| 8A | Basic push-button controlled LED operation. |
| 8B | LED toggling using button press detection and software debouncing. |
| 8C | Short-press and long-press detection for LED toggling and blinking. |

## Hardware Used
- STM32F103C8T6 (Blue Pill)
- Push Button
- Red LED
- 330 Ω Resistor

## Pin Configuration

| Pin | Function |
|---|---|
| PA0 | Push Button Input |
| PA3 | LED Output |

## Key Concepts
- GPIO Input and Output
- Active-LOW button configuration
- Software Debouncing
- Button Press Duration Detection
- LED Toggle and Blink Control
